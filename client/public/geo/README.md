# Country boundaries

`countries.geojson` is Natural Earth's 1:50m admin-0 country boundary dataset from the Natural Earth vector repository:

https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

The file is served locally and includes a separate Kosovo feature. The dashboard draws these polygons without a tile service. Attribution is shown on the map.
